Garbage Day, sorted by the era it's talking about

Pull quotes from public issues, placed by the era they're about, not the week they went out. The yellow highlight is the exact phrase that dates each quote.

How the quotes are checked
  • The model never writes quote text. It sees each issue as numbered sentences and returns only sentence numbers, and code copies the quote from the issue.
  • Each issue is handled on its own, and code attaches the issue link, so a quote can't end up under the wrong issue.
  • Every date has to be backed by an exact phrase from the same paragraph. If the phrase isn't there, or the years don't make sense, the quote is rejected and counted.
  • A separate review then reads each quote on its own, the way you see it here. It cuts any quote that only mentions its era in passing, like a "back in the 2010s… but now" setup or a background date in a story about today. A quote stays only if it tells you something about the era it's filed under.
  • "Nothing in this issue is about the past" is an acceptable answer, so there's no pressure to fill the timeline.
