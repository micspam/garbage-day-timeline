Garbage Day, sorted by the era it's talking about

Pull quotes from public issues, placed by the era they're about, not the week they went out. The yellow highlight is the exact phrase that dates each quote; a dashed ~year means the text names an era, not a year.

How the quotes are checked
  • The model never writes quote text. It sees each issue as numbered sentences and returns only sentence numbers, and code copies the quote from the issue.
  • Each issue is handled on its own, and code attaches the issue link, so a quote can't end up under the wrong issue.
  • Every date has to be backed by an exact phrase from the same paragraph. If the phrase isn't there, or the years don't make sense, the quote is rejected and counted.
  • A separate review then reads each quote on its own, the way you see it here, and cuts anything that only mentions its era in passing.
  • Tags for platforms, people and audiences also need an exact phrase from the text, or they're dropped. Nothing is tagged "TikTok" unless the text says TikTok.
