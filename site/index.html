Garbage Day, by the era it's talking about

Pull quotes from public issues, placed on the timeline by the time period they reference, not when they were published. Scroll sideways.

How the quotes are checked

The model never writes quote text. It only picks sentence numbers, and the quote is copied from the issue by code, so it can't make up a quote. It also has to cite an exact phrase that dates the reference (a year, an era, an event), and anything it cites that isn't in the issue is thrown out. Issues with no past references are allowed to return nothing.
